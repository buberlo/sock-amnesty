# Sock Amnesty

> Track missing socks as fugitives and bribe the dryer for clemency.

A household laundry web app that assigns a heat level to every unpaired sock and builds a small fugitive board for them. You can clear cases by proving pairs, accepting oddball losses, or paying the dryer in virtual coins. It ends each laundry cycle with a sock amnesty report and a dryer chaos meter.

## Features
- Pair registry with photo, location, and last-seen wash tag
- Fugitive heat score that rises when the same sock goes missing repeatedly
- Dryer bribe economy using coins earned from completed loads
- Weekly amnesty report with missing-sock map and household score

## Stack
- Next.js
- SQLite
- Tailwind CSS
- Recharts

## Getting started
```
npm install && npm run dev
```
